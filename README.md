# Blogger by Vi

## Description

This website features, HTML, Javascript and CSS artfully combined to create a personal blogging website. Whether this site acts as a journal, personal blog or notetaking platform, it saves all previous entries in local storage and displays them whenever a new post is added. This site features light and dark mode configurations, and a simplistic UI.
